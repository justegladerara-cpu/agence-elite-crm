Cette branche contient l'ancien prototype **Elite Hôtel**. Il n'est plus un projet actif depuis le 1er octobre 2026, sur décision de Juste.

- La dernière version fonctionnelle est le commit `20f4bbc`, parent direct de ce commit d'archivage.
- Le site publié par cette branche n'affiche plus qu'un avis d'archive. L'ancienne application installée se retire d'elle-même.
- Côté Supabase (projet kangourou-gestion), les tables `h_*` sont rangées dans le schéma `archive_elite_hotel_a_supprimer`, sans aucun droit d'accès. Les comptes propres à l'hôtel sont désactivés.
- Une sauvegarde complète se trouve dans le dossier projet `archive/a-supprimer/elite-hotel/`.
- **Ne pas réutiliser comme base de la future plateforme.**
- Le logiciel **Le Kangourou** (branche `claude/project-thread-bm6nwc`) n'est pas concerné.
